# Aerial 1.57 手机遥控改版

基于 app.orchard.tv 的 Aerial 1.57 universal 的个人改版：把 tv-vibehack v2.5 的手机遥控移植进 Aerial。

## 功能

- 手机遥控：电视在 8898 端口提供网页遥控，扫码配对；触控板单指移动指针、双指滚动、轻点点击；方向键一按一格。
- 桌面顶排原信号源格改为遥控格（手机图标），点开显示配对二维码。
- 壁纸格保持原选壁纸功能；壁纸屏二维码统一为遥控码；遥控页带“壁纸管理”入口，跳转电视自带的 8790 传图服务。
- 设置里音量与亮度显示百分比。
- 设置顶排信号源／网络／设置，在手机遥控和电视原装遥控下都是左右一按一跳。
- 界面跟随系统语言。

## 安装须知

- 本改版签名与原版不同，安装前须先卸载电视上的原版 Aerial，原设置会丢失。
- 装后需在电视设置 → 无障碍里手动开启一次“TV 手机遥控”服务。
- 后续同签名改版可直接覆盖安装，无需再卸载。
